The other two tabs both show the same thing: a single flat PM–vs–PdM call, once per PI. That’s literally all the published v0.8 engine models — it has no pods, no directors, no GM. This tab is a new extension, built for this demo, that runs the actual cadence the org chart implies: Pod Sync (the 3–4 pod leaders) → Sprint Review (director/VP) → Pre-GM (staging & triage) → GM meeting, which should mostly just be informed — and only spend its own time on whatever is still genuinely unresolved. It reuses v0.8’s real bid/mandate/backlog formulas at every tier (same ranges, same rank-gap discount, same backlog math) — it just applies them across three pods and four meetings instead of one flat comparison. It is not part of the published repo.
