# H-006: Capacity-Orchestration Consequence Governance

## Status

**Prospective / pre-registered design. Baseline not yet executed.**

This directory contains the frozen experimental specification and baseline
parameter registry for H-006.

The design is intentionally being completed before baseline execution so that
capacity physics, treatment boundaries, and analysis definitions cannot be
changed in response to observed results.

Any parameter still marked `TBD` blocks execution.

## Current Execution Gate

The architecture is frozen, but baseline execution is intentionally blocked
until all required parameter-registry fields are resolved.

Open items include environment and initialization assumptions, agent-policy
configuration, trust initialization, and several measurement-definition choices.

The purpose of this gate is to prevent changing model assumptions after
observing results.
