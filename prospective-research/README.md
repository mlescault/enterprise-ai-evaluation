# H-006: Capacity-Orchestration Consequence Governance

## Status

**Prospective design / preregistration in progress. Baseline not yet executed.**

This directory contains the frozen experimental specification and the developing baseline parameter registry for H-006.

The treatment architecture and experimental boundaries are frozen. Baseline parameter values, statistical planning, and several capacity-physics definitions are still being finalized before execution.

The design is intentionally being completed before baseline execution so that capacity physics, treatment boundaries, analysis definitions, and acceptance criteria cannot be changed in response to observed results.

Any parameter still marked `TBD`, or any unresolved modeling definition identified in the parameter registry, blocks baseline execution.

H-006 should therefore be interpreted as evidence of prospective experimental-design and preregistration discipline, not as an executed experiment or completed experimental finding.
