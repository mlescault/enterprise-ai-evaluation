Simulation Engines
This directory contains executable simulation engines supporting the enterprise AI evaluation case studies in this repository.

Current Status
The first published simulation artifacts will document the evolution from Engine v0.7 to v0.8, including:

the original implementation that produced a false-positive result
the corrected execution path
the subsequent self-audit that identified a second measurement issue
supporting result and sensitivity-analysis artifacts
Simulation source will be added after a public-release review for reproducibility, documentation, and removal of any environment-specific or non-public information.
